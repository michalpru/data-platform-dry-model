# Contributing

The Data Platform DRY Model is a single-author reference model. All content: the whitepaper, supplementary docs, assessment tables, diagrams, examples, and templates - is maintained and evolved by the author to ensure consistency and integrity of the Model.

## Feedback and error reports

Feedback is welcome via [GitHub Issues](https://github.com/michalpru/data-platform-dry-model/issues). Use an issue to:

- report a typo, broken link, or factual error
- ask a question about the model or its application
- suggest an example or pattern for the author to consider adding

Issues are reviewed periodically. There is no guaranteed response time.
